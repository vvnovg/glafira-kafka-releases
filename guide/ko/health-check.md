# 클러스터 점검과 메모

Glafira는 기본 제공 규칙으로 클러스터를 점검하고, 찾은 문제를 개체 옆에 보여 줍니다. 연결 트리, 토픽과 그룹 목록, 토픽과 그룹 화면에 표시됩니다. LLM 어시스턴트는 이 발견 사항에 자신의 메모를 덧붙일 수 있습니다. 점검은 클러스터를 읽기만 하며 아무것도 바꾸지 않습니다.

<a id="run"></a>

## 점검 실행

연결의 **클러스터 개요** 화면이나 **발견 사항** 탭을 열고 **클러스터 점검** 버튼을 클릭하세요. 점검은 최대 45초가 걸립니다. Glafira는 브로커, 파티션, 토픽 설정(토픽 최대 2000개), 컨슈머 그룹(최대 500개)을 읽습니다. 토픽이나 그룹이 이 한도를 넘거나, 읽지 못한 항목이 있거나, 45초가 지나면 결과에 **일부만 점검됨** 표시가 붙고, **불완전한 점검** 항목에 읽지 못한 내용이 나옵니다.

Glafira는 스스로 클러스터를 조회하지 않습니다. 점검은 버튼을 클릭하거나 LLM 어시스턴트가 요청할 때만 실행됩니다. 결과는 다음 점검까지 보관됩니다.

<a id="rules"></a>

## 점검 항목

- 브로커와 파티션: 컨트롤러 없음, 사용할 수 없는 파티션과 복제 부족 파티션, 브로커가 하나인 클러스터, 리더 편중, 선호 복제본에 있지 않은 리더.
- 토픽 내구성: 복제 계수 1, 복제 계수보다 큰 `min.insync.replicas`, 복제 계수와 같은 `min.insync.replicas`, `min.insync.replicas` 값 1, 언클린 리더 선출.
- 브로커 설정: 토픽 자동 생성, 기본 복제 계수 1, 기본 `min.insync.replicas` 값 1, 브로커마다 다른 중요 설정.
- 컨슈머 그룹: 랙이 있는 빈 그룹, 리밸런싱 중인 그룹, 파티션이 없는 멤버, 이전 점검 이후 늘어난 랙.

<a id="severity"></a>

## 심각도와 환경

발견 사항마다 심각도가 있습니다: **심각**, **경고**, **정보**. 심각도는 연결 환경에 따라 다릅니다. 예를 들어 복제 계수 1은 prod에서 심각, stage에서 경고이고 dev, test, local에서는 표시되지 않습니다. 환경은 연결 양식에서 설정합니다.

<a id="tab"></a>

## 발견 사항 탭

**발견 사항** 탭에서는 발견 사항이 규칙별로 묶여 있고, 항목마다 문제와 조치가 설명됩니다. **심각도**, **출처**, **개체** 필터로 거르거나 이름으로 검색하세요. 개체 이름을 클릭하면 해당 화면이 열립니다.

연결 트리와 토픽·그룹 목록의 숫자 배지는 해당 개체에 관련된 발견 사항과 열린 LLM 메모 중 심각도가 **심각** 또는 **경고** 수준인 항목의 수를 보여 줍니다. 배지에 포인터를 올리면 이 항목들의 제목을 볼 수 있습니다.

<a id="hide"></a>

## 발견 사항 숨기기

특정 개체에서 예상된 발견 사항이라면(예: prod에 있는 복제 계수 1의 테스트 토픽) **이 개체에서 숨기기** 버튼을 클릭하세요. 숨긴 발견 사항은 배지 수에 포함되지 않고 이후 점검에서도 숨겨진 채로 유지됩니다. 숨긴 항목을 보려면 '숨긴 항목 표시'를 켜세요. 그곳에서 **되돌리기** 버튼을 클릭할 수 있습니다.

<a id="notes"></a>

## LLM 메모

MCP로 연결된 LLM 어시스턴트([LLM 어시스턴트(MCP)](llm-mcp.md#how-it-works) 참고)가 클러스터, 브로커, 토픽, 그룹에 대한 메모를 남길 수 있습니다. 메모는 **LLM 메모** 섹션과 개체 화면에 클라이언트 이름과 함께 표시됩니다. 텍스트는 서식이나 링크 없이 그대로 표시됩니다.

- **해결됨**, **해당 없음** 버튼: 메모를 닫습니다. 닫힌 메모는 접힌 섹션에 남습니다.
- **삭제** 버튼은 메모 하나를, **LLM 메모 모두 삭제** 버튼은 연결의 모든 메모를 삭제합니다.
- 메모는 만든 지 7일이 지나면 자동으로 삭제됩니다. 연결 하나에 열린 메모는 최대 200개입니다.

<a id="with-llm"></a>

## LLM 어시스턴트와 함께

어시스턴트는 `health_check` 도구로 같은 점검을 실행하고 같은 발견 사항을 봅니다. 숨긴 발견 사항도 숨김 표시와 함께 포함됩니다. 마지막 점검이 5분이 지나지 않았다면 어시스턴트는 클러스터를 다시 조회하지 않고 그 결과를 받습니다. 예를 들어 "클러스터 상태를 점검하고 가장 중요한 문제에 메모를 남겨 줘"라고 요청해 보세요.
