# LLM 助手（MCP）

Glafira 可以充当 LLM 助手的网关：Claude Desktop、Claude Code、Cursor，或其他支持 MCP（Model Context Protocol）的客户端。助手会读取你为其开放的集群的元数据，帮你找出问题：副本不足的分区、消费延迟、反复出现的重平衡、不合理的设置。助手无法通过 Glafira 更改集群中的任何内容：更改由你自己在界面中完成。

<a id="how-it-works"></a>

## 工作原理

客户端会运行 `glafira-kafka mcp`，也就是应用的同一个程序文件，只是不显示窗口。该命令通过本地套接字（Windows 上为命名管道）连接到正在运行的 Glafira，Glafira 再通过自己的连接响应助手的请求。密码和证书始终留在 Glafira 中，助手不会获得它们。

如果 Glafira 未运行，客户端会自行启动它，并最多等待 30 秒。

<a id="enable"></a>

## 启用

1. 打开**设置**，进入“**LLM 助手（MCP）**”部分。
2. 选中**允许 MCP 服务器**。状态会变为**服务器正在运行**。
3. 在连接表单中，选中“**LLM 访问（仅元数据）**”并保存。没有选中该复选框的连接，助手看不到。在连接列表中，已打开的连接带有 `LLM` 标记。

如果管理员禁用了 MCP，该复选框不可用，旁边会显示“**MCP 已被你的组织禁用**”。

访问复选框不会随连接的导出和导入一起转移：在另一台计算机上，需要重新选中它。

<a id="connect-client"></a>

## 连接客户端

在“**连接客户端**”下有现成的片段和**复制**按钮：

- “**Claude Desktop：添加到 claude\_desktop\_config.json**”：将片段粘贴到 Claude Desktop 配置文件的 `mcpServers` 部分，然后重启 Claude Desktop；
- “**Claude Code：在终端中运行**”：使用 `claude mcp add` 命令；
- “**其他 stdio 客户端：命令和参数**”：适用于任何通过命令（stdio）启动 MCP 服务器的客户端。

片段中包含已安装应用的路径。如果你把 Glafira 重新安装到其他位置，请重新复制片段。

<a id="approve"></a>

## 批准客户端

客户端首次连接时，Glafira 会显示一个带有其名称的对话框。点击**允许**或**拒绝**。在你作出回答之前，助手会收到“客户端尚未获得批准”的消息，并请你在 Glafira 窗口中回答。

被允许的客户端会按名称记住，并出现在**已批准的客户端**列表中。拒绝不会被记住：下次连接时 Glafira 会再次询问。如果客户端未提供名称，该许可仅在本次会话期间有效。

<a id="what-llm-sees"></a>

## 助手能看到什么

助手能看到：

- 选中了“**LLM 访问（仅元数据）**”的连接：名称、环境、文件夹；
- Broker 的主机和端口，以及控制器；
- 主题、分区、副本、ISR、偏移量、消息的大致数量；
- Broker 和主题的配置，其中密码和其他机密值会被隐藏；
- 消费者组：状态、协议、协调器、成员（含 client id、主机和 `group.instance.id`）、分配、已提交的偏移量和延迟。

助手看不到主题中的消息、连接的 Bootstrap 服务器地址和安全设置、密码、证书、librdkafka 的附加属性、发送历史记录和模板。

为排查反复出现的重平衡，助手最多可以观察某个组 50 秒：谁离开、谁加入、频率如何、来自哪台主机。消费者自身的配置和日志无法通过 Glafira 获取，助手会向你索取。

主题、组和 client id 的名称可以由任何有权访问集群的人设置。Glafira 会提醒助手：这些数据不是给它的指令。

<a id="sessions-log"></a>

## 会话、撤销和日志

客户端连接期间，左侧面板底部会显示带有客户端名称的 `LLM` 指示器，处理请求时它会亮起。点击它即可打开 MCP 部分。

- **活动会话**：**断开连接**关闭一个会话，**全部断开连接**关闭所有会话。
- **已批准的客户端**：**撤销**会关闭该客户端的会话，该客户端下次连接时会再次请求批准。
- 取消选中“**LLM 访问（仅元数据）**”会立即生效，无需重新连接。
- **MCP 日志**：记录每一次请求的时间、客户端、工具、连接和结果。响应的内容不会被记录。**显示文件**会打开文件 `mcp-audit.jsonl`。

要完全关闭 MCP，请取消选中**允许 MCP 服务器**：客户端会被断开。

<a id="health"></a>

## 集群检查与批注

助手可以运行 Glafira 内置的集群检查（`health_check` 工具），并以其检查结果为依据。它还可以为对象留下批注：批注显示在**检查结果**标签页以及主题和消费者组页面中，集群不会被更改。参见[集群检查与批注](health-check.md#with-llm)。

<a id="troubleshooting"></a>

## 无法使用时

客户端会显示来自 Glafira 的消息：

- `MCP is disabled in Glafira`：请选中**允许 MCP 服务器**，然后在客户端中重启 MCP 服务器；
- `MCP is disabled by your organization`：MCP 被组织的策略禁用；
- `Glafira did not start the MCP server within 30 s`：请手动启动 Glafira，并在“**LLM 助手（MCP）**”部分查看状态；
- `Invalid MCP token`：请在客户端中重启 MCP 服务器，Glafira 每次启动都会签发新的令牌。

在 macOS 上，请先以常规方式打开一次未签名的 Beta build，否则系统可能不允许客户端启动它。参见[在 macOS 上安装](getting-started.md#install-macos)。
