# クラスターのチェックと注記

Glafiraは組み込みのルールでクラスターをチェックし、見つかった問題をオブジェクトのそばに表示します。接続ツリー、トピックとグループの一覧、トピックとグループの画面です。LLMアシスタントは、これらの検出事項に独自の注記を追加できます。チェックはクラスターを読み取るだけで、何も変更しません。

<a id="run"></a>

## チェックの実行

接続の**クラスターの概要**または**検出事項**を開き、**クラスターをチェック**をクリックします。チェックには最大45秒かかります。Glafiraはブローカー、パーティション、トピック設定（最大2000トピック）、コンシューマーグループ（最大500）を読み取ります。トピックやグループがこの上限を超える場合、読み取れないものがあった場合、または45秒が経過した場合は、結果に**一部のみチェック**と表示され、検出事項**不完全なチェック**で読み取れなかった内容がわかります。

Glafiraが自分からクラスターを問い合わせることはありません。チェックが実行されるのは、ボタンをクリックしたときかLLMアシスタントが要求したときだけです。結果は次のチェックまで保存されます。

<a id="rules"></a>

## チェックの内容

- ブローカーとパーティション：コントローラーがない、利用できないパーティションとレプリカ不足のパーティション、ブローカーが1台のクラスター、リーダーの偏り、優先レプリカにないリーダー。
- トピックの耐久性：レプリケーションファクター1、レプリケーションファクターを超える`min.insync.replicas`、レプリケーションファクターと同じ`min.insync.replicas`、`min.insync.replicas`が1、アンクリーンなリーダー選出。
- ブローカーの設定：トピックの自動作成、デフォルトのレプリケーションファクターが1、デフォルトの`min.insync.replicas`が1、ブローカー間で異なる重要な設定。
- コンシューマーグループ：ラグのある空のグループ、リバランス中のグループ、パーティションのないメンバー、前回のチェックから増えたラグ。

<a id="severity"></a>

## 重要度と環境

検出事項にはそれぞれ重要度があります：**重大**、**警告**、**情報**。重要度は接続の環境によって変わります。たとえばレプリケーションファクター1は、prodでは重大、stageでは警告になり、dev、test、localでは表示されません。環境は接続フォームで設定します。

<a id="tab"></a>

## 「検出事項」タブ

**検出事項**タブでは、検出事項がルールごとにまとめられ、それぞれに問題の説明と対処が表示されます。**重要度**、**ソース**、**オブジェクト**で絞り込むか、名前で検索できます。オブジェクト名をクリックするとその画面が開きます。

接続ツリーとトピック・グループの一覧に表示される数字付きのバッジは、そのオブジェクトに関する検出事項と開いているLLMの注記のうち、重要度が**重大**または**警告**のものの数を示します。バッジにポインターを合わせると、それらのタイトルが表示されます。

<a id="hide"></a>

## 検出事項の非表示

特定のオブジェクトで想定どおりの検出事項（たとえばprodにあるレプリケーションファクター1のテスト用トピック）なら、**このオブジェクトで非表示**をクリックします。非表示にした検出事項はバッジに数えられず、以降のチェックでも非表示のままです。非表示の検出事項を見るには「非表示を表示」をオンにします。そこで**元に戻す**をクリックできます。

<a id="notes"></a>

## LLMの注記

MCPで接続したLLMアシスタント（[LLMアシスタント（MCP）](llm-mcp.md#how-it-works)を参照）が、クラスター、ブローカー、トピック、グループについての注記を残せます。注記は**LLMの注記**とオブジェクトの画面に、クライアント名付きで表示されます。テキストは書式やリンクなしでそのまま表示されます。

- **解決済み**と**該当なし**は注記を閉じます。閉じた注記は折りたたまれたセクションに残ります。
- **削除**は注記を1件削除し、**LLMの注記をすべて削除**は接続のすべての注記を削除します。
- 注記は作成から7日後に自動で削除されます。1つの接続で開いている注記は最大200件です。

<a id="with-llm"></a>

## LLMアシスタントと使う

アシスタントは`health_check`ツールで同じチェックを実行し、同じ検出事項を確認します。非表示の検出事項も、非表示であることがわかる形で含まれます。前回のチェックから5分たっていなければ、アシスタントはクラスターに再度問い合わせずにその結果を受け取ります。たとえば「クラスターの状態をチェックして、最も重要な問題について注記を残して」と依頼してください。
